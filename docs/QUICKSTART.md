# 五分鐘開始使用

[回到專案首頁](../README.md) · [官方下載](https://github.com/OverGreen996/Babelander2/releases/tag/v2.0.0a23)

## 免安裝版

1. 下載 `Babelander2-v2.0.0a23-windows-x64.zip`，**完整解壓縮**。保留 `Babelander2.exe` 與 `_internal` 的相對位置，不要只搬 EXE。
2. 執行 `Babelander2.exe`，開啟「設定」。使用本機翻譯時，透過程式內的資源下載區取得模型與 runtime，或指定已有的相容檔案。資源約 1.93 GB，建議預留至少 4 GB 空間；下載需要網路，完成後本機 OCR／翻譯可離線使用。
3. 可先預載模型，避免第一句包含冷啟動時間。選擇模式並框選文字所在區域。字幕／聊天可持續監測；裝備／任務／框選翻譯執行一次。

目前 Windows x64 是測試平台；CUDA 本機路徑使用 NVIDIA GPU。其他硬體請先從 CPU 模式測起，本版未驗證所有 GPU。

## 日常操作

| 想做什麼 | 操作 |
|---|---|
| 看劇情字幕 | `Ctrl + Alt + F1` 框選，再用 `Ctrl + Alt + F2` 開始／停止 |
| 讀裝備 | `Alt + T` 框選；在原區域覆蓋一次，隱藏後看回原卡 |
| 看任務 | 工作台選「任務卡」，框選任務欄或日誌 |
| 讀隊伍聊天 | `Ctrl + Alt + C` 框選聊天區，開始監測 |
| 中文回英文 | `Ctrl + Alt + R`；產生英文後自己複製送出 |
| 看其他文字 | `Ctrl + Alt + S` 框選 |
| 顯示／隱藏字幕浮層 | `Ctrl + Alt + F3` |
| 切換字幕浮層背景 | `Ctrl + Alt + F4` |

快捷鍵可在設定修改。若快捷鍵被其他程式占用，改用工作台按鈕。首次實機建議使用視窗或無邊框模式，只框必要文字，先確認辨識與覆蓋位置。

## 資料與隱私

- 預設設定、一般模式快取、歷史及加密金鑰位於 `%LOCALAPPDATA%\Babelander2`。這些不是 GitHub 原始碼的一部分。
- 聊天室固定本機翻譯；聊天與中文回覆不寫入 SQLite 歷史、快取或用量紀錄。工作台及浮層仍會在記憶體顯示內容。
- 其他模式可選 Google、Azure 或 DeepL；選擇雲端服務時，文字會送往該服務商，並適用其計費規則。中文回覆也可能使用所選雲端服務。
- 模型閒置預設 300 秒可卸載，停止工作時也會依使用狀態釋放程式自行啟動的模型。卸載是釋放 RAM／VRAM，下載檔案仍保留。

## 常見狀況

**第一句比較慢**：先預載模型。README 的延遲數據為暖機後測量，不含模型首次載入。

**抓不到字或黑畫面**：縮小框選範圍、調整遊戲顯示模式，並以一般視窗文字交叉確認。受保護畫面、獨佔全螢幕或部分浮層尚未保證相容。

**譯文不對**：停止監測，查看辨識截圖／原文，修改後重翻；專有名詞可加入「我的詞庫」。數值與語意仍應自行核對。

**浮層擋住操作**：在工作台隱藏浮層，或恢復浮層互動後移動它。裝備與任務覆蓋設計為貼合原框選區域。

**要回報問題**：到 [Issues](https://github.com/OverGreen996/Babelander2/issues)，附版本、Windows／GPU、模式、框選大小及問題描述。分享截圖前先移除私人聊天與 API 金鑰。
